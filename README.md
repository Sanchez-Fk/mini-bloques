# Mini Bloques

Juguetería de figuras de mini bloques. Catálogo con la foto real de cada caja y el personaje armado en 3D (Three.js), carrito y pedido por WhatsApp.

- Sitio estático: `index.html`, `js/modelos.js`, `img/`.
- `herramientas/`: cuadrículas de cada figura y scripts para regenerar las imágenes.
